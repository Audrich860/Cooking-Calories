# Cooking Calories

A board game and companion website that raises awareness of calorie intake and balanced diets, with a focus on teenage obesity.



## About the project

Teenage obesity is often linked to a lack of knowledge about balanced diets, as well as the price and availability of healthy food. Cooking Calories turns those ideas into a game. Players cook dishes from four ingredient shops, balance their food intake against exercise, and try to finish close to their character's calorie goal.

The game is adapted from the board game Rival Restaurants. The nutrient shops, net calorie scoring, character cards and trivia challenges are our own additions.

## How the game works

- 4 players, each starting with 300 coins and receiving more every hour
- Each hour has four phases: get money and place teenagers, buy ingredients, make a dish, and draw an activity card
- Four shops sell carbs, protein, fats and fibres, each with different prices
- Healthy dishes have fewer calories but cost more, while unhealthy dishes are cheaper with more calories
- If two players want the same ingredient, they compete with a trivia question
- Net calories (food minus exercise) are compared with the character's goal at the end

## The website

The site includes:

- A how-to-play page
- A playable solo companion that tracks coins and net calories, with input validation
- Net calorie and allowance calculators
- Reference tables for the characters, ingredients and dishes

It is a single `index.html` file built with HTML, CSS and JavaScript, with no external libraries.

## Subjects covered

- **Biology:** balanced diets and nutrient groups
- **Maths:** the allowance function 
- **Economics:** prices, scarcity and the cost of healthy food
- **Chemistry:** compounds in each nutrient group
- **Physics:** energy conversions in food and exercise
- **Computer science:** the interactive website

## Run it locally

Download `index.html` and open it in any web browser. No installation is needed.

## Notes

Calorie values are rounded estimates for game purposes, not medical advice.
